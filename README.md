# 2023 Mini Projects

A collection of beginner-friendly HTML and CSS projects I built in 2023 while learning the fundamentals of front-end web development through freeCodeCamp.

These projects document my early practice with semantic HTML, forms, page layout, typography, responsive design, and CSS styling.

## Projects

The repository contains a series of standalone mini projects, including:

- **Cafe Menu** — a styled cafe menu with drinks, desserts, prices, and footer information.
- **CatPhotoApp** — a simple HTML page featuring images, lists, links, and a cat information form.
- **Colored Markers** — a CSS illustration of red, green, and blue markers.
- **Registration Form** — a form demonstrating text fields, passwords, radio buttons, checkboxes, file uploads, and select menus.
- **Survey Form** — a freeCodeCamp-style survey form with user details, dropdowns, radio buttons, checkboxes, and comments.
- **City Skyline** — a CSS-only city skyline illustration built with layered building shapes.
- **Magazine Layout** — a magazine-style article layout using typography, images, columns, and social links.
- **Product Landing Page** — a trombone product page with navigation, features, video content, and pricing cards.

Additional projects are organized in numbered folders throughout the repository.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox and layout techniques
- Forms and built-in HTML validation
- External fonts, icons, and images from freeCodeCamp resources

## How to Run the Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/dadnaa/2023-mini-projects.git
   ```

2. Open the repository in your code editor.
3. Open any project's `index.html` file in a web browser.

For a smoother development experience, use a local extension such as **Live Server** in Visual Studio Code.
